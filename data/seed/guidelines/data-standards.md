# Data and Reconciliation Standards (Synthetic Prototype Excerpt)

> Prototype Dataset — Synthetic Data. Paraphrased for demonstration purposes only.

## Record Completeness

Every work record should carry a valid location (coordinates within the
district), consistent dates (recommendation before sanction, sanction before
start, start before completion), and a current progress figure. Records failing
these checks are routed for correction to the implementing agency; corrections
are made at source so downstream analysis reflects verified values.

## Cross-System Reconciliation

Payments recorded against a work should reconcile with treasury transactions
referencing that work's code within the prescribed tolerance and time window.
Transactions that reference unknown or outdated work codes are investigated as
probable clerical errors first. An amount gap that survives verification with
the disbursing office is escalated with the documented difference.

## Corrections and Audit Trail

Data corrections record who corrected what, when, and on what authority. The
original value is preserved in the audit trail. Analytical outputs are
recomputed after corrections so that risk indicators always reflect the current
verified record.
